# JetX Audit Report — 2026-04-29

Baseline: post-rename `Get* → Jet*`, package `jetx 1.0.0-dev.1`, ~20.6k LOC, 134 dart files. `flutter analyze` clean (1 unrelated import).

Severity legend:
- **BUG** — functional defect (wrong result, crash, data loss)
- **SECURITY** — exploitable / weakens transport security
- **LEAK** — memory / timer / subscription / controller not released
- **API** — bad public surface (type erasure, footgun, undocumented contract)
- **SMELL** — antipattern, perf cliff, dead code, branding leftover

Each entry: `severity | path:line | what | why bad | fix`.

Verified items have `[v]` marker (re-read source after agent reported). Unverified are agent-reported only — confirm before patching.
